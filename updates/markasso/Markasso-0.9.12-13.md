# Markasso 0.9.12

- Cloud boards are safer: edits made while a change was being sent are no longer lost when you close the window, a board you open again no longer reports a conflict that is not there, and a locked Keychain no longer makes a valid license key look refused.
- Opening an edit link for a board that already has a different one now asks before replacing it (Keep Current Link is the default), so a wrong link cannot take the place of the right one.
- The Command Palette (Command-K) has Share: it copies the board's share link, like File > Copy Share Link.
- The minimap shows a new canvas background at once, and the shortcut reference lists Settings and Hide Interface.
- Boards and share links that the web opens now open here too: files starting with a byte order mark and some compressed share links were refused before.

- Le lavagne cloud sono più sicure: le modifiche fatte mentre una modifica veniva inviata non vanno più perse alla chiusura della finestra, una lavagna riaperta non segnala più un conflitto inesistente, e un Portachiavi bloccato non fa più sembrare rifiutata una chiave di licenza valida.
- Aprire un link di modifica per una lavagna che ne ha già uno diverso ora chiede prima di sostituirlo (il predefinito è Mantieni il link attuale), così un link sbagliato non può prendere il posto di quello giusto.
- Il Riquadro comandi (Comando-K) ha Condividi: copia il link di condivisione della lavagna, come File > Copia link di condivisione.
- La minimappa mostra subito un nuovo sfondo della tela, e l'elenco delle scorciatoie include Impostazioni e Nascondi interfaccia.
- Le lavagne e i link di condivisione che il web apre ora si aprono anche qui: prima venivano rifiutati i file che iniziano con un byte order mark e alcuni link di condivisione compressi.
