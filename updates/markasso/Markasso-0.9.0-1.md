# Markasso 0.9.0

The first public build of Markasso for Mac, a beta.

- Boards as Mac documents: autosave, versions, tabs, the Boards panel with the history by day.
- Every web tool, the inspector, the library with icon packs, presets, the command palette and element search.
- Quick Look previews and Finder thumbnails, Spotlight search, printing, Share Image and a text Service.
- Files open unchanged on the web app and back.
