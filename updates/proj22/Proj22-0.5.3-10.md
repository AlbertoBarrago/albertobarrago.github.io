## Proj22 0.5.3

- **Menu bar**: opening another copy of Proj22 now activates the running app instead of starting a second
  instance with a duplicate timer in the menu bar. The second copy exits before opening the timer database.

## Proj22 0.5.3 (italiano)

  istanza con il timer duplicato nella barra menu. La seconda copia esce prima di aprire il database del timer.
