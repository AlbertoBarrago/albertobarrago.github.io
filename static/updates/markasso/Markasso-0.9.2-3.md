# Markasso 0.9.2

- **Cloud boards.** File → Cloud Board → Save to Cloud puts a board on markasso.it: it stays in sync between the Mac and the browser, works offline, and asks how to resolve a conflict (Keep Mine, Take Theirs or Save a Copy). Read and edit links, Open Link…, `markasso://` links and Handoff come with it. Creating and saving cloud boards needs a Markasso Cloud subscription (Settings → Cloud): reading them and share links stay free.
- **Start screen and templates.** With no board open, the Boards window offers a blank board, a template or a link. Seven templates are built in, and File → Save as Template… adds your own.
- **Assistant (preview).** Ask about the board or describe a change, then apply the proposal as one undo step (`⌘J`). It uses your own Anthropic or OpenAI key, or a local server such as Ollama or LM Studio. Turn it off in Settings → Assistant if you don't want it.
- **New Tab** (`⌘T`), and the **+** at the end of the tab bar.
- Settings are split into tabs: General, Appearance, Cloud and Assistant.

- **Lavagne nel cloud.** Archivio → Lavagna nel cloud → Salva nel cloud mette una lavagna su markasso.it: resta sincronizzata tra il Mac e il browser, funziona offline e chiede come risolvere un conflitto (Tieni la mia, Prendi la loro o Salva una copia). Con loro arrivano i link di lettura e di modifica, Apri link…, i link `markasso://` e Handoff. Per creare e salvare lavagne nel cloud serve un abbonamento Markasso Cloud (Impostazioni → Cloud): leggerle e i link di condivisione restano gratuiti.
- **Schermata di apertura e template.** Senza lavagne aperte, la finestra Lavagne propone una lavagna vuota, un template o un link. Ci sono sette template, e Archivio → Salva come template… aggiunge i tuoi.
- **Assistente (anteprima).** Chiedi qualcosa sulla lavagna o descrivi una modifica, poi applica la proposta in un solo passo annullabile (`⌘J`). Usa la tua chiave Anthropic o OpenAI, o un server locale come Ollama o LM Studio. Se non ti serve, spegnilo in Impostazioni → Assistente.
- **Nuovo pannello** (`⌘T`), e il **+** in fondo alla barra dei pannelli.
- Le Impostazioni sono divise in schede: Generale, Aspetto, Cloud e Assistente.
